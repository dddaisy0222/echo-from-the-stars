# Echo｜来自星星的我

Echo 是一个以“自我”为核心的时空探索式互动体验。它将人的记忆、愿望与未选择的人生转化为一张可以穿梭的内在星图，让用户与过去、未来和平行世界中的自己对话。

## 体验闭环

1. 创建代表当下状态的“星核”
2. 在时间与可能性构成的星图中选择一个自我切片
3. 与另一个自己建立跨时空通讯
4. 完成对话后收到一封星际信笺

## 为什么做 Echo

当 AI 越来越擅长给出答案，我们更想探索另一种关系：AI 不替人做决定，而是将散落的生命碎片重新编织，以“镜像自我”的方式帮助人看见自身的可能性。

## 当前原型

这是为黑客松准备的交互式 MVP。它使用可直接体验的示例星核和本地生成的对话逻辑展示完整产品路径，不收集或上传用户输入。后续版本可以接入长期记忆、个性化人格建模、语音克隆与生成式对话服务。

## 本地运行

```bash
npm install
npm run dev
```
